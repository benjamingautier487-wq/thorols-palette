Installer sur iPhone & iPad

Transformez Thorol's Palette en véritable application plein écran sur votre écran d'accueil iOS / iPadOS :

  1. 1 Ouvrez cette page dans Safari sur votre iPhone ou iPad (après avoir saisi votre code Cloud).
  2. 2 Touchez le bouton Partager (carré avec flèche vers le haut) dans la barre de Safari.
  3. 3 Faites défiler et choisissez « Sur l'écran d'accueil » puis touchez Ajouter.
